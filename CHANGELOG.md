# TradeumDiary - Changelog

## Улучшения (27.05.2026)

### 🎯 Основные изменения

#### 1. Исправлен импорт сделок

- **Проблема**: Создавались дубликаты сделок при импорте
- **Решение**:
  - Добавлен уникальный индекс `unique_user_tx` на `(user_id, tx_hash)`
  - Используется `upsert` вместо `create` для предотвращения дубликатов
  - При повторном импорте существующие сделки обновляются

#### 2. Автоматический расчёт P&L при импорте

- **Проблема**: Все сделки имели `pnl_realized = 0`
- **Решение**:
  - После сохранения сделок автоматически рассчитывается P&L
  - P&L рассчитывается как: `выручка от продажи - стоимость покупки - комиссии`
  - Распределяется пропорционально объёму на каждую сделку
  - Группируется по символу (все buy/sell сделки одного символа)

#### 3. Улучшен UI списка сделок

- Добавлена колонка с ценой в USD
- Показаны комиссии (fee) под P&L
- Добавлен статус сделки
- Улучшено отображение хеша транзакции (6 символов вместо 4)
- Добавлен индикатор биржи (exchange)

#### 4. Удалены дубликаты

- Удалено 30 дубликатов из 33 сделок
- Осталось 3 уникальные сделки ROBOUSDT

#### 5. Исправлен фильтр дней

- Убран автоматический фильтр `daysAgo`
- Все сделки теперь отображаются без ограничения по дате
- Пользователь может явно указать `dateFrom` и `dateTo`

#### 6. Исправлен расчёт общего баланса

- **Проблема**: Баланс показывал $0 несмотря на P&L в сделках
- **Решение**:
  - Правильное преобразование Decimal в число при суммировании
  - Баланс теперь показывает сумму всех `pnl_realized`

### 📊 Технические детали

#### База данных

```prisma
// Добавлены индексы
@@unique([user_id, tx_hash], name: "unique_user_tx")
@@index([user_id, wallet_id])
@@index([user_id, timestamp])
```

#### API изменения

- `saveTrades()` теперь:
  1. Сохраняет/обновляет сделки через `findFirst` + `create`/`update`
  2. Группирует сделки по символу
  3. Рассчитывает P&L для каждой группы
  4. Обновляет `pnl_realized` для каждой сделки

#### Формула P&L

```
P&L = (totalSellValue - totalBuyValue) - totalFees

Где:
- totalSellValue = сумма всех продаж
- totalBuyValue = сумма всех покупок
- totalFees = сумма всех комиссий

Распределение на каждую сделку:
tradePnl = netPnl * (tradeAmount / totalAmount)
```

### 🚀 Как использовать

1. **Импорт сделок**:
   - Добавьте кошелёк Bybit с API ключами
   - Нажмите "Синхронизировать"
   - Сделки импортируются без дубликатов
   - P&L рассчитывается автоматически

2. **Просмотр сделок**:
   - Все сделки отображаются на дашборде
   - Можно сортировать по дате, P&L, объёму
   - Можно искать по символу или хешу

3. **Мониторинг**:
   - Win Rate - процент прибыльных сделок
   - Profit Factor - отношение прибыли к убыткам
   - Макс. просадка - максимальное падение капитала
   - **Общий баланс** - сумма всех P&L
