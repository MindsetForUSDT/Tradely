### ❌ Проблемы

- Кнопка "Возможности" скроллила на ту же секцию (пользователь уже там)

### 💡 Решение

#### NewHeroSection.tsx

```typescript
- Добавлены refs для скролла к секциям
- handleScrollToFeatures → скролл к NewFeaturesSection
- handleScrollToAuth → скролл к auth-section
- Кнопка "Начать бесплатно" → ссылка на /subscribe
- Кнопка "Зарегистрироваться" → Link to="/subscribe"
- Форма входа → disabled (нет функционала)
```

#### Landing.tsx

```typescript
- Добавлен ref для NewFeaturesSection
- Обёртка div с ref для корректного скролла
- Скролл к секции работает правильно
```

## 2️⃣ Обновление дизайна (по референсам)

### Стиль:

- **Минимализм** (как на kodacode.ru, alvar-aalto.tilda.ws)
- **Плавные градиенты** (indigo → emerald → amber)
- **Качественная типографика** (Inter, JetBrains Mono)
- **Светлые акценты** на тёмном фоне
- **Мягкие тени** и border с прозрачностью

### Обновлённые компоненты:

#### NewHeroSection.tsx

```tsx
- Убран canvas (частицы)
- Добавлены градиентные пятна (indigo/emerald)
- Минималистичная форма входа (white/5 фон)
- Кнопки:
  - "Начать бесплатно" → белый фон, чёрный текст
  - "Возможности" → GlowButton outline
  - "Контакты" → border white/10
- Статистика с иконками
```

#### NewFeaturesSection.tsx

```tsx
- Минималистичные карточки (white/5 фон)
- Градиентное свечение при наведении
- Иконки с цветным градиентом
- Без изображений (только иконки + текст)
- Плавные переходы (duration-300)
- Hover: scale-105 + shadow-2xl
```
