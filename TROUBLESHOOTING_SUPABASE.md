# 🔧 Диагностика проблем с Supabase

## Симптомы

- ❌ Запросы превышают 15 секунд
- ❌ Ошибка: `net::ERR_CONNECTION_RESET`
- ❌ Ошибка: `503 Service Unavailable`
- ❌ Дашборд не загружается

---

## 🚨 Быстрая диагностика (5 минут)

### Шаг 1: Проверьте статус Supabase

🔗 https://status.supabase.com

Если есть красные индикаторы → проблема на стороне Supabase, ждите.

---

### Шаг 2: Проверьте ваш проект

🔗 https://app.supabase.com/project/TradeumD

**Что проверить:**

1. Статус базы данных (должно быть "Active")
2. Если "Paused" → нажмите "Start"
3. Подождите 1-2 минуты после старта

---

### Шаг 3: Простая проверка API

Откройте в браузере:

```
https://zfgeofskmgycojbzrznk.supabase.co/rest/v1/
```

**Ожидаемый результат:** JSON с сообщением "API is running"

**Если ошибка:**

- 404 → API выключен
- 503 → Сервис недоступен
- Не грузится → проблема с сетью

---

### Шаг 4: Проверьте таблицу через SQL Editor

🔗 https://app.supabase.com/project/TradeumD/sql

Выполните:

```sql
SELECT COUNT(*) FROM public.wallets;
```

**Если не выполняется** → база данных недоступна.

---

## 🔧 Решения

### Решение 1: Перезапустить базу (если остановлена)

1. Dashboard → Settings → Database
2. Нажмите "Start" или "Resume"
3. Подождите 1-2 минуты

---

### Решение 2: Проверить лимиты тарифа

Бесплатный тариф Supabase:

- База может "засыпать" после 1 часа бездействия
- Первые запросы занимают 30-60 секунд
- Ограничение: 500MB хранения

**Проверка:** Dashboard → Settings → Usage

---

### Решение 3: Обновить приложение несколько раз

Если база "просыпается" - попробуйте обновить страницу 2-3 раза.

---

### Решение 4: Проверить сеть

1. Откройте https://google.com - работает?
2. Откройте https://supabase.com - работает?
3. Откройте https://zfgeofskmgycojbzrznk.supabase.co/rest/v1/ - работает?

Если только последний не работает → проблема с Supabase.

---

### Решение 5: Очистить кэш браузера

1. F12 → Network tab
2. Нажмите "Disable cache"
3. Обновите страницу (Ctrl+Shift+R)

---

## 📊 Статус проекта

| Проблема                    | Решение                 | Время     |
| --------------------------- | ----------------------- | --------- |
| База остановлена            | Start в Dashboard       | 1-2 мин   |
| Supabase outage             | Ждать восстановления    | 10-60 мин |
| Сетевая проблема            | Проверить firewall      | 5 мин     |
| Первый запуск после простоя | Подождать "пробуждения" | 30-60 сек |
| Лимиты превышены            | Увеличить тариф         | -         |

---

## 📞 Если ничего не помогает

1. Откройте Dashboard → Settings → Database
2. Скопируйте **Connection string**
3. Попробуйте подключиться через pgAdmin или DBeaver
4. Если не подключается → откройте тикет в Supabase Support

---

## ✅ После восстановления

1. Проверьте что загрузился дашборд
2. Попробуйте добавить кошелёк
3. Проверьте что загрузились сделки

Если проблема вернётся → сделайте скриншот ошибок из консоли (F12).
