## 📊 Пользовательский путь (полный)

### Сценарий 1: Новый пользователь

```
1. Заход на /
   └─> Видит современный лендинг с анимациями
   └─> Скроллит к секциям функций
   └─> Нажимает "Начать бесплатно"

2. Форма регистрации
   └─> Вводит email и пароль
   └─> Нажимает "Создать аккаунт"
   └─> Перенаправление на /subscribe

3. Выбор тарифа
   └─> Видит FREE и PRO тарифы
   └─> Выбирает FREE (бесплатно)
   └─> Перенаправление на /dashboard

4. Первый вход в дашборд
   └─> Видит пустой дашборд
   └─> Нажимает "Подключить кошелёк"
   └─> Добавляет кошелёк (Web3 или адрес)
   └─> Система импортирует сделки
   └─> Видит аналитику
```

### Сценарий 2: Пользователь хочет PRO

```
1. В дашборде → кликает "PRO" в меню
   └─> Переход на /subscribe

2. Выбирает PRO тариф
   └─> Нажимает "Оформить PRO"
   └─> Переход на /payment

3. Оплата
   └─> Вводит данные карты
   └─> Оплачивает 499₽
   └─> Перенаправление на /dashboard

4. После оплаты
   └─> Доступны все PRO функции
   └─> Badge "PRO" в интерфейсе
```

### Сценарий 3: Возвращающийся пользователь

```
1. Заход на /
   └─> Автоматический вход (сессия в localStorage)
   └─> Header показывает имя пользователя
   └─> Клик по логотипу → /dashboard

2. В дашборде
   └─> Видит все сделки
   └─> Аналитика в реальном времени
   └─> Может добавлять новые кошельки
```
